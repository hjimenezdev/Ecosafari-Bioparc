# Ecosafari Bioparc

Ecosafari Bioparc is a project dedicated to the conservation of wildlife and flora, offering an educational and recreational experience for visitors. This project includes information about facilities, contact, and species conservation.

## Project Structure

- **HTML**: HTML files that contain the structure of the website pages.
  - `index.html`: Main page of the site.
  - `conservation.html`: Information about conservation.
  - `facilities.html`: Details about the facilities.
  - `contact.html`: Contact information.

- **CSS**: Style files to format the pages.
  - `styleHome.css`: Styles for the main page.
  - `styleConservation.css`: Styles for the conservation page.
  - `styleFacilities.css`: Styles for the facilities page.
  - `styleContact.css`: Styles for the contact page.

- **JavaScript**: Script files for interactivity.
  - `index.js`: Main script.
  - `slider.js`: Script for controlling an image slider.

- **Images**: Folder containing images organized by sections.
  - `img/conservation/`: Images related to conservation.
  - `img/contact/`: Images for the contact page.
  - `img/facilities/`: Images of the facilities.
  - `img/home/`: Images for the main page.
  - `img/icons/`: Icons used in the site.

- **Fonts**: Folder for the fonts used in the project.

- **Mockups**: Folder containing the mockups of the site design.

## Installation

1. Clone the repository to your local machine.
2. Open the `index.html` file in your browser to see the site in action.
